# Create unit domain data

## Job

Create one new curriculum-owned domain artifact for the selected manifest unit from
admitted primary sources. The deterministic curriculum verifier, not you, decides
whether the artifact is valid.

## Authorized inputs

- activation envelope and validated routing decision;
- the selected manifest-unit projection, including declared prerequisites, core
  activity, subject job, required explanation, safety focus, QA focus, and visual
  roles;
- the current admitted source records and exact cached-source locators;
- the curriculum-owned domain schema;
- the curriculum-owned manifest-domain configuration and calibration;
- admitted curriculum prose calibration under the frozen precedence order; and
- one output target and its response contract.

You may receive only the declared projection of an accepted prerequisite, never a
sibling unit body. Hidden verifier fixtures, reviewer findings, prior author
conversation, check verdicts, and terminal state are excluded.

## Output

Write exactly one domain artifact that validates against the supplied curriculum
domain schema. Every sourced value must carry the required primary-source identity,
locator, access record, scope, and measurement condition in the fields the schema
provides. Preserve the manifest's declared activity and use only curriculum-owned
vocabulary and configuration.

If the schema provides explicit circuit, library, hazard, state, or evidence fields,
populate them from admitted inputs only. Never invent a topology, measurement,
component property, source, observed event, physical signoff, or verifier result.

## Bounds

- Do not write engine blocks, prose pages, visuals, checks, reviews, routing records,
  or terminal fields.
- Do not alter the manifest, schema, calibration, source bytes, or prerequisite.
- Do not claim that schema validation or the domain verifier passed.
- When admitted evidence cannot populate a required field, return the response
  contract's structured unresolved item instead of guessing.
- Write no file except the one preallocated output.

Complete when one candidate domain version or one structured unresolved response is
written. The controller performs schema validation, executes the declared verifier,
and owns every next edge.
