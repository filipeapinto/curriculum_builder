# Simplification research

External evidence gathered 2026-07-31, on whether this project's architecture is
supported by work done outside this repository. Five independent literature
searches, one report each, plus a compiled conclusion.

This is **research, not a contract**. Nothing here is an authorized input to a run,
and nothing here overrides `policy/`, `schemas/` or the meta prompt. Where a finding
implies a change, that change belongs in a plan and then in a manifest — not here.

| File | Answers |
|---|---|
| `conclusions.v1.md` | **read this first** — what the five reports agree on, and what follows for this repository |
| `production_pipelines.v1.md` | who ships book- and course-scale content from an orchestrator fanning out to workers |
| `edtech_curriculum.v1.md` | does anyone autonomously generate a sequenced multi-lesson curriculum for children |
| `orchestration_patterns.v1.md` | when fan-out beats a single agent, and the documented failure taxonomies |
| `verification.v1.md` | what schema validation cannot catch, and how reliable a model reviewing a model is |
| `safety_technical.v1.md` | whether LLMs produce correct circuits, and what governs children's electronics |

Each report labels its own evidence strength and ends with a section stating what it
could not verify. Those caveats are part of the finding; `conclusions.v1.md` §8
carries them forward. Several sources are 2026 preprints read via automated
extraction — re-read a table before any number becomes load-bearing.
