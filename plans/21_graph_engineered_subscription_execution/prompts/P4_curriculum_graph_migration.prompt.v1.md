checkpointed deterministic task within a node, with a documented one-to-one

2. **P4-T02 — Reachability.** Union of tested live/negative paths reaches every frozen state and legal terminal.
3. **P4-T03 — Plan 19 disposition.** Every conflict-map entry is implemented unchanged/retargeted/retired/superseded exactly as P0 recorded; no stale contradictory prompt remains active.

5. **P4-T05 — Gemini retirement.** Production runtime/policy contains no Gemini command, key, route, or fallback; historical evidence is untouched.
6. **P4-T06 — Session bridge disposition.** Manual intermediate authoring is impossible; facade tests prove graph delegation or the module is retired safely.
7. **P4-T07 — Deterministic rendering.** Structured unit fields render as learner prose/forms, never raw JSON; unknown required fields fail.
8. **P4-T08 — Visual truth.** Declared visual roles resolve to semantically correct, subject-visible assets or a non-accepting state; no generic fallback invents relations.
9. **P4-T09 — Claim evidence.** Exact subject, locator, entailment, derivation, and visual visibility checks bind each external/safety/numeric claim.
10. **P4-T10 — POE semantics.** Prediction, observable event, recorded evidence, explanation, and visual refer to the same event.
11. **P4-T11 — Required-check completeness.** Every required check records PASS/FAIL/NOT_RUN/BLOCKED; absent checks cannot be acceptance-neutral.
12. **P4-T12 — Failure classification.** Only a named unavailable safety-critical external fact can BLOCK; factory/tool/schema/render defects follow their frozen classes.
13. **P4-T13 — Targeted revision.** One failed check changes only its owned artifact/node; all accepted sibling hashes remain identical.
14. **P4-T14 — Interrupt/resume, phase ledger, and corruption split.** Arbitrary interruption replays only absent/incomplete runtime and P4 migration-ledger work; committed migration units never repeat. Hash mismatch/corrupt/unauthorized mutation fails closed with forensic bytes and no manual repair.
15. **P4-T15 — Neutral engine.** A non-electronics fixture supplies its own roles, vocabulary, ids, schemas, and verifier without engine edits.
16. **P4-T16 — Manifest order.** Unit order and completion derive from the frozen manifest, never filesystem enumeration.
17. **P4-T17 — Run lifecycle.** Partial/interrupted/blocked/failed/complete coverage is schema-valid and cannot falsely report complete.
18. **P4-T18 — Workbook immutability.** Workbook repair cannot mutate accepted unit content and cannot assemble incomplete coverage.
19. **P4-T19 — Receipt compatibility.** Final evidence consumes normalized P2 receipts end to end without provider-shaped assumptions.
20. **P4-T20 — Prompt/version binding.** Every model artifact binds prompt, graph, route, model-registry, policy, and schema digests.
21. **P4-T21 — Negative path suite.** Illegal transition, skipped state, duplicate completion, stale hash, broad rewrite, false block, and judge bypass all fail before terminal write.
22. **P4-T22 — Existing runtime suite.** No unclassified regression relative to P0; dirty-baseline failures are compared by stable id, not raw exit code alone.
23. **P4-T23 — Applicable gates.** Every gate actually executes tests; new/worsened results fail unless P0 explicitly authorized the change.
24. **P4-T24 — Live full-state unit.** A fresh-root unit traverses the compiled graph with no prewritten/manual worker artifact and a complete, recomputable trace.
