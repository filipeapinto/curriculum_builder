usage: python3 -m runtime.run_curriculum [-h] --engine-root PATH
                                         --curriculum PATH --output-root PATH
                                         (--preflight | --unit UNIT_ID |
                                         --all | --resume)
                                         [--authorization PATH]

Sole production CLI entry to the compiled Plan 26 curriculum factory.

options:
  -h, --help            show this help message and exit
  --engine-root PATH
  --curriculum PATH
  --output-root PATH
  --preflight           read-only readiness check; creates no run
  --unit UNIT_ID        run one requested unit plus its prerequisite closure
  --all                 run the full exact manifest
  --resume              resume a legally resumable episode
  --authorization PATH  external-data authorization record; required for
                        --unit, --all, and --resume
