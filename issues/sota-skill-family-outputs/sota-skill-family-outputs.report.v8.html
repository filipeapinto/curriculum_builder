The two SOTA studies used different structures, records, checks, and result states

Executive summaryTriggerIndependent verificationRoot causeCorrectionsRisksHuman decision

Executive summary

The user noticed that two SOTA studies were organized and verified very differently. The resulting investigation confirmed that the studies used different artifact locations, record formats, lifecycle evidence, verification outcomes, and final-state language; it also found defects inside both runs. Some differences were legitimate because the studies asked different questions. The current evidence does not prove which exact SOTA skills or agents executed the historical runs. The recommended correction is to define one compact SOTA run structure, one SOTA-owned plan template, explicit result states, and checks that apply to every SOTA run.

Trigger

The user observed that research/codex_calls_claude_qa_gate/ and research/codex_same_model_qa_gate/ differed substantially. The user created identify-sota-family-inconsistencies.prompt.md to determine which differences were legitimate, which were defects, why they occurred, and what should change.

Root-cause analysis

Root cause: The SOTA family states shared research controls, but the concrete locations, record shapes, lifecycle states, verification checks, and final-result terms are supplied by each plan and run. The family does not currently bind those elements to one enforced contract.
