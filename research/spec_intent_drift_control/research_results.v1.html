When the spec starts steering you

Repeated LLM review can make a specification more coherent, testable—and less yours. The risk is not disorder. It is confident convergence on a recursively manufactured objective.

Verdict Do not execute v11 unchanged.

Re-anchor it with an independent intent probe, then authorize only a reversible, budget-capped slice. The goal is to regain steering information, not to perfect the document.

01 · Reframing

This is not document governance

In agentic work, the specification is simultaneously a memory artifact, a prompt, an evaluator target, a coordination protocol, and an authorization surface. A rewrite does not merely edit requirements; it changes what future agents will notice, optimize, test, and treat as legitimate. OpenAI describes agents as shifting work from short interactions to delegated, long-horizon tasks, while Anthropic frames effective agent work as a problem of selecting and maintaining the right context over time. OpenAI · Anthropic

01

Generation is cheaper than comprehension

Agents can add detail faster than a human can rebuild a causal model. Review debt grows even when prose quality improves.

02

Context is a lossy runtime

Long-horizon agents rely on compaction, structured notes, and delegated summaries. What survives becomes operational truth; omitted rationale becomes practically nonexistent. Source

03

The evaluator can mutate the target

If tests, rubrics, and critiques are derived from the current spec, the system can optimize self-consistency while original intent disappears.

04

Reviewers are not independent samples

Model judges exhibit self-preference and preference leakage; same-family or related generator–judge pairs can share biases. EMNLP 2025 · Preference leakage

05

Agreement may be persuasion

Multi-agent debate is not reliably truth-seeking by default; protocol, diversity, judge design, and external evidence matter. ICML study · Adversarial influence study

06

Action has compounding cost

Long-running agents can expand files, schemas, tests, and dependencies in parallel. The control objective must include reversibility, information gain, and spend—not only task completion.

02 · System dynamics

How reciprocal review loses the owner

The AI-native failure is objective laundering. An agent introduces a reasonable design choice; another agent critiques its completeness rather than its authority; the revision encodes it as normative; fixtures are generated from it; later reviewers see a tested requirement. Provenance has been replaced by internal coherence.
03 · Repository evidence

v11 did not suddenly drift. The product changed shape early.

Local inspection shows that v1 was a 14.5 KB, model-agnostic reader-facing documentation standard. By v2–v5 it had become a repository-specific three-skill system with artifact schemas, decision ownership, run configuration, conformance states, and approval workflow. From v7 onward the eleven-section structure stabilizes. v10→v11 is small. This is a repository observation, not an external claim.

05 · Proposed control architecture

Keep the owner outside the recursive objective

The owner should not approve every edit. The owner should control the few variables agents must not manufacture: desired outcomes, prohibited outcomes, risk/cost boundaries, and decisions that change those boundaries. Everything else can remain agentic.

Key design rule: agents may propose changes to the intent kernel but cannot write them into force. The kernel is deliberately small; the high-volume detail lives in an append-only graph and is continuously challenged by evidence.
06 · Next action

Run a divergence probe, not a full audit

The cheapest high-information move is to ask independent systems to reconstruct the product from different evidence boundaries, then measure where their predicted behaviors diverge. Do not let them rewrite v11 during the probe.

01FreezeHash v1–v11, schemas, fixtures, prompts, and available transcripts. Set a hard research budget.
02Three blind reconstructionsA: original prompts + v1. B: owner interview only. C: v11 only. Use different model families where possible.
03Generate witnessesEach produces ten concrete “the system will / will not” predictions, costs, dependencies, and irreversible effects.
04FalsifyIndependent agents seek repository evidence and counterexamples. Judges see anonymized outputs in randomized order.
05Owner adjudicates deltasOnly material disagreements reach the owner. Approve a tiny reversible slice or stop.

Pilot authorization rule

Proceed only if the owner recognizes the v11 reconstruction as the desired product, all three lanes agree on the first reversible slice, and no disputed dependency, publication authority, architecture choice, or cost driver is hidden inside that slice. Otherwise, reconstruct a candidate from the owner lane plus repository evidence rather than polishing v11.

Current decision: RE-ANCHOR + PROBE. Not “execute,” not “rewrite everything,” and not “add more reviewers.” v11 remains evidence and a candidate implementation hypothesis.
07 · What this review changes

Corrections to the first research pass

From traceability matrix to event-sourced intent graph

A static matrix assumes stable artifacts and manageable change volume. An append-only graph better represents agent-generated proposals, evidence, decisions, supersessions, and unresolved contradictions without letting a rewrite erase provenance.

From human approval everywhere to uncertainty-triggered authority

Humans cannot review agent-volume output. Their scarce attention should be routed to semantic novelty, boundary changes, disagreement, spend, and irreversible actions.

From acceptance tests to orthogonal eval lanes

Tests derived from the current spec are endogenous. AI-native control requires at least one evaluation lane whose origin is outside the artifact being optimized.

From independent reviewers to independence engineering

Different prompts are not independent. Blindness, model-family diversity, randomized presentation, distinct evidence access, adversarial incentives, and human calibration create partial independence.

From complete planning to reversible information gain

Because agents make implementation cheap and plans rapidly stale, the next authorized unit should maximize uncertainty reduction while bounding downside—not attempt to specify the entire final system.
