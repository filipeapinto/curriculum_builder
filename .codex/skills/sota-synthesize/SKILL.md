# SOTA Synthesize

1. Accept only identified, appraised evidence products authorized by the plan.
2. Synthesize within evidence class before comparing across standards, research, implementations, and practice.
3. Build mechanism-by-failure-mode and mechanism-by-repository-fit comparisons.
4. Give every finding a stable ID; separate evidence strength from applicability.
5. Link each recommendation to findings, incident relevance, implementation cost, residual risk, and proving tests.
6. Retain contradictions, negative evidence, limitations, and unknowns.
7. Send claims and recommendations to `$sota-independent-challenge`; disposition every returned challenge.

Return comparative findings, recommendations, limitations, and challenge dispositions. Do not self-accept the research.
