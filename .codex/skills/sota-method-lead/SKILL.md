# SOTA Method Lead

Use the approved plan as the sole study-specific contract beneath the non-waivable `../sota-plan-execute/references/sota-family-contract.md`. Reject any plan interpretation that weakens the family baseline.

1. Translate its questions, scope, eligibility, appraisal, extraction, and synthesis rules into bounded assignments.
2. Freeze queries, criteria, schemas, identifiers, budgets, and acceptance gates before collection.
3. Monitor evidence coverage, selection consistency, convergence, and deviations.
4. Reject silent scope, eligibility, budget, or method changes. Return material changes to `$sota-plan-create` for vN+1.
5. Keep proposed decisions distinct from human approvals.

Return these records through the canonical run log/report package: frozen protocol interpretation, assignment boundaries, coverage state, deviations, and unresolved authority decisions. Do not accept the final research.
